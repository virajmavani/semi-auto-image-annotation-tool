GETTING STARTED
===============

1. Setup Backend:
   cd web/backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install torch torchvision

2. Setup Frontend:
   cd web/frontend
   npm install

3. Run Backend:
   cd web/backend
   source venv/bin/activate
   python main.py

4. Run Frontend (new terminal):
   cd web/frontend
   npm run dev

5. Open Browser:
   http://localhost:3000

Or use the start script (Linux/Mac):
   cd web
   ./start.sh

WORKFLOW
========

Upload → Select Labels → Auto Detect → Manual Adjust → Save

1. User uploads image (frontend)
   ↓
2. Image sent to backend, saved, dimensions returned
   ↓
3. User selects labels and clicks "Detect"
   ↓
4. Backend runs RetinaNet inference
   ↓
5. Detections sent back to frontend
   ↓
6. Bounding boxes drawn on canvas
   ↓
7. User can draw more boxes or edit existing
   ↓
8. User clicks "Save"
   ↓
9. Backend writes CSV and VOC XML files
   ↓
10. Success message shown to user


DEPENDENCIES SUMMARY
====================

Backend (Python):
  - FastAPI         (web framework)
  - PyTorch         (ML inference)
  - Torchvision     (RetinaNet model)
  - Pillow          (image processing)
  - Uvicorn         (ASGI server)

Frontend (Node):
  - React           (UI library)
  - TypeScript      (type safety)
  - Vite            (build tool)
  - TailwindCSS     (styling)
  - Konva.js        (canvas rendering)
  - Axios           (HTTP client)


PORTS
=====

Backend:  http://localhost:8000
Frontend: http://localhost:3000
API Docs: http://localhost:8000/docs


OUTPUT
======

Annotations saved to:
  - CSV: web/backend/annotations/annotations.csv
  - XML: web/backend/annotations/annotations_voc/*.xml

Format:
  CSV: image_path,x1,y1,x2,y2,label
  XML: Pascal VOC format
