## 📝 Documentation Conventions

### File Naming
- `UPPERCASE.md` - Documentation files
- Descriptive names (README, QUICKSTART, etc.)

### Section Numbering
- Use markdown headers (##, ###)
- No manual numbering
- Table of contents where helpful

### Code Examples
- Syntax highlighting with language tags
- Comments for clarity
- Full context when needed

### Links
- Relative links between docs
- External links in full
- Anchor links for long documents
